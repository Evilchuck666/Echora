Your collection. Your server.

A self-hosted music streaming API for your own FLAC and MP3 library. Echora keeps the music on your server and gives clients a shared way to browse and play it.

Get started

Start your music server

The backend runs in Docker Compose. Follow the README to configure the music folder, import your collection and connect Echora Web. This page introduces the project; listening requires your own running server.

Set up Echora ↗
git clone https://github.com/Evilchuck666/Echora.git
cd Echora
docker compose build --pull
docker compose up --wait
